# Hail Mary 1.4 — Interface redesign

A shared charcoal-and-orange interface replaces the sidebar dashboard. The title screen has larger lunar artwork, mission selection cards, a direct hangar action, and a resume-flight action when a flight is active. Named top navigation stays available on desktop and phone.

The hangar puts the model and propellant beside equipment and preflight checks on wide screens, then stacks them on smaller screens. Equipment descriptions, status text, command choices and navigation use a more readable type scale. Flight and result screens share the same buttons, surfaces and navigation.

Mission rules and saved-flight format are unchanged. Browser verification covers all mission routes, impact and escape outcomes, retry, import/export, keyboard input, reduced motion, fallback rendering, 390/768/1440 layouts and automated accessibility.
