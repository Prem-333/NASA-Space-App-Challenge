# Hail Mary 1.3 — Flight outcomes

Flight mode now puts a large follow-camera playfield beside a command dock, with compact navigation and telemetry. Keys 1–3 activate the displayed command choices.

Ignoring a navigation update loses the lunar encounter. Skipping orbital capture sends the craft past the Moon. An uncontrolled surface approach produces an impact flash and debris, then signal loss. Failed attempts terminate and remain in the archive. These are explicitly scripted educational scenarios.

Every completed flight has a prominent success or failure screen, with the specific outcome, a retry button, and spacecraft modification. Successful landings show touchdown; a safe arrival that misses its science target still fails the objective.

Validation includes deterministic outcomes and saved-state replay, 57 reachable starter branches, crash/escape/success browser flows, retry and keyboard controls, mobile layout and accessibility.
